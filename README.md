# ELARA Cosmetics

ELARA Cosmetics is a modern, responsive e-commerce website for beauty and skincare products.  
It showcases a variety of products, offers, and new launches, with a smooth, user-friendly interface.

## Features

- Home page with hero banner, offers, and new launches.
- Product sections for **Face, Eyes, Brushes, and Skin**.
- **Login / Signup** buttons for user authentication (frontend only for now).
- **Orders** and **Add to Cart** links for a realistic shopping experience.
- Responsive design with hover effects on products.
- Easy navigation and clean UI/UX.

## Tech Stack

- **HTML5 & CSS3**
- **Bootstrap 5**
- Vanilla **JavaScript** for interactivity
- Local image assets for product display
